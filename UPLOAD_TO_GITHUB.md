# Upload this package to a new GitHub repository

1. Create a new empty GitHub repository.
2. Extract this ZIP on your computer.
3. Upload the **contents inside** `Weir-research-article-Phase10-ready/` to the repository root (do not upload the outer folder as an extra nesting level).
4. Commit the uploaded files to `main`.
5. Send the new repository URL back to ChatGPT.
6. ChatGPT can then inspect the repository, run the controlled static/scientific checks, review paths/imports, and guide GitHub Pages/browser acceptance.

For GitHub Pages after the repository is verified: Settings → Pages → Deploy from a branch → `main` / `(root)`.
